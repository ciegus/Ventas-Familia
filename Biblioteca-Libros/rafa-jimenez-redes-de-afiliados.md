# Conocer las Redes de afiliados — Rafa Jiménez

## 1. Idea central
El modelo de "comercial externo" permite pagar solo por objetivos cumplidos (venta o registro). Ideal para optimizar presupuestos ajustados donde cada euro debe retornar en conversión directa.

## 2. Frameworks y modelos clave
- **eCPM:** `eCPM = Ingresos / (Impresiones / 1000)` — para comparar canales.
- **Registro de empresa (8 pasos):** contactar la red → negociar el fee → determinar comisiones por objetivo → establecer política de promoción → subir creatividades (estándares IAB) → preparar texto comercial para afiliados → insertar píxel de conversión → aceptar afiliados manual o por red.

## 3. Pasos accionables
1. Contactar una red de afiliados y negociar el fee.
2. Definir comisiones por objetivo (venta/registro).
3. Subir creatividades y texto comercial estandarizado.
4. Insertar píxel de conversión y aceptar afiliados.

## 4. Errores comunes a evitar
- Pérdida de control sobre el emplazamiento de los anuncios.
- Fraude en registros (leads falsos).

## 5. Aplicable a Ventas Familia
El fee mensual de hasta 600€ de las grandes redes puede no ser asumible. Si el presupuesto es limitado, tratar directo con blogs locales ofreciendo comisión por venta, sin costos fijos de plataforma.

## 6. Frase para recordar
> "La Red de afiliados vive de la comisión que el anunciante paga al afiliado."
